# 🐙 GitHub User Finder

A simple web app to fetch and display GitHub user details using the **GitHub API**.  
Built with **HTML, Vanilla JS (async/await, fetch API), and TailwindCSS**.

---

## 🚀 Features
- Search any GitHub user by username
- Displays:
  - 👤 Name
  - 🆔 User ID
  - 🔑 Login
  - 📦 Public Repositories Count
- Error handling for:
  - Empty input
  - Invalid usernames
- Responsive, dark-themed UI with TailwindCSS
